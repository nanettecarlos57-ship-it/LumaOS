# LumaOS

**Your Android. A New Experience.**

LumaOS is an original native Android launcher inspired by useful interaction patterns from multiple iOS generations. It is being developed with Kotlin and Jetpack Compose.

## Planned features

- iPhone-inspired home screen, dock, folders and app library
- Customizable icons, widgets, themes and wallpapers
- Quick-settings-inspired Control Center
- Dynamic Island-inspired notifications and activity display
- Lock-screen companion experience
- Notification presentation, gestures and animations
- Free core experience with optional premium customization

## Technology

- Kotlin
- AndroidX and Jetpack Compose
- Gradle
- GitHub Actions (planned for automated builds)

## Android support

The initial target is Android 6.0 (API 23) and newer. Individual capabilities will depend on Android version, device manufacturer and user-granted permissions. A third-party launcher cannot replace every protected Android system function.

## Build

Open the repository in Android Studio, allow Gradle sync to complete, then run the `app` configuration on an emulator or Android device.

## Project status

Early project foundation. The starter screen is in place; app discovery, persistent home-screen layout, widgets, gestures and the other launcher modules are still to be implemented.
